# Fullstack Prototype – Role-Based App (DelaCruz)

## 📌 Project Overview

This project demonstrates the migration of a **Role-Based Single Page Application (SPA)** into a **Full-Stack Application** using **Node.js and Express.js**.

It builds on a previous frontend-only project and introduces a backend server for handling authentication and role-based access control.

---

## 🚀 Features

* Role-based authentication (e.g., Admin, User)
* Backend server using Node.js & Express
* Frontend interface with HTML, CSS, and JavaScript
* API communication between frontend and backend
* Organized project structure

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/your-username/your-repo.git
cd fullstack-prototype-DelaCruz
```

### 2. Install backend dependencies

```bash
cd role-based-app-backend
npm install
```

### 3. Run the backend server

```bash
npm start
```

Server will typically run on:

```
http://localhost:3000
```
